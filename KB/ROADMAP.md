# Этапы и критерии завершения

| Этап | Проверяемый результат |
|---|---|
| 0. Проектирование | Пакет предложений готов к независимому ревью. Переход к фундаменту после утверждения владельцем |
| 1. Инженерный фундамент | Git main и рабочая ветка, шаблон PR и CHANGELOG, минимальный каркас утверждённого стека, lock, Compose, безопасный .env.example, все команды ENGINEERING. На чистой машине воспроизводятся сборка, миграция и smoke. Неверный тестовый адрес отклоняется. На согласованном GitHub remote пробный PR показывает работающий gate и доступный уровень защиты |
| 1a. Визуальный прототип | Рабочие образцы профиля, каталога и формы оценки проверены в браузере. Владельцем утверждён визуальный образец до масштабирования компонентов. См. [процесс и критерии](DESIGN.md#прототип-и-приёмка) |
| 2. Каталог и доступ владельца | На синтетических данных доступны вход, поиск, выбор целого произведения и приватная библиотека. Проверены чужая сессия, выход и повторная загрузка. Для реального каталога согласованы права и условия источника |
| 3. Библиотека и оценивание | Согласованы переходы, валидация и округление. U01–U05 воспроизводятся. Формула, нули, конкурентное сохранение, обновление тегов и откат покрыты проверками |
| 4. Рекомендации и обмен ссылкой | Утверждены доступ гостя и видимые поля. U06–U09 проходят в независимых сессиях. Приватные поля защищены сервером. Описание рекомендации отделено от комментария |
| 5. Приёмка MVP | Согласованные образцы профиля и каталога сверены в браузере, мобильные/настольные снимки приложены. Успешны полный прогон, Docker smoke и проверка восстановления БД. CHANGELOG и тег соответствуют принятому релизу. Публикация по разрешению владельца |

Проверки UI выполняются также в каждом затрагивающем его этапе. Отложенные функции перечислены в [продукте](PRODUCT.md).
