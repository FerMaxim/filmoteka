# Этапы и критерии завершения

Стадии, ответственные, блокировки и выкладки — в [BACKLOG](BACKLOG.md).

| Этап | Зависимость | Критерий завершения |
|---|---|---|
| 0. Проектирование | — | Архитектура проверена и утверждена владельцем. |
| 1. Фундамент | 0 | Нативный запуск из PowerShell, миграции, smoke и PostgreSQL на CI с успешным quality-gate. |
| 1а. Визуальный прототип | 1, утверждённый эталон | Приёмка по [DESIGN](DESIGN.md#прототип-и-приёмка). |
| 2а. Серверная основа | 1а | Вход, синтетический поиск, приватное добавление, повтор и чтение после перезапуска. Права проверены в разных сессиях. |
| 2б. Основа Kinopoisk | 2а | T-008: поиск, кеш и импорт по [CATALOG](CATALOG.md), тесты на fixtures. |
| Публичный каталог | 2б | [T-010](TASKS/T-010.md): гостевое чтение, личные права, безопасный возврат к сценарию. |
| Регистрация MVP | 2а, общий сценарий с T-010 | [T-011](TASKS/T-011.md): регистрация, подтверждение почты, вход, выход и восстановление пароля. |
| Гостевой Kinopoisk и допуск | 2б и публичный каталог | [T-012](TASKS/T-012.md): внешняя выдача, защита квоты, проверка прав и режим постеров. |
| 3. Библиотека и оценивание | 2а, согласованные переходы T-010/T-011 | T-007, U01–U05, R45/R46. Формула, нули, теги, конкурентная запись и откат проверены. |
| 4. Рекомендации и обмен ссылкой | 3 | U06–U09 в отдельных сессиях. Гостевые поля и приватность по R45. |
| 5. Готовность к эксплуатации | 4, публичный каталог, регистрация и допуск необходимых интеграций | Приняты основные пути и визуальные образцы, full, production check и HTTPS smoke пройдены. Восстановление, откат, reboot и мониторинг проверены по [OPERATIONS](OPERATIONS.md). CHANGELOG и тег соответствуют выпуску. Владелец разрешил запуск. |
| 6. Сопровождение | 5 | Обслуживание, наблюдение, копии, обновления и инциденты по OPERATIONS. |

Подготовка среды и согласованные тестовые показы могут идти параллельно продуктовым этапам. Значимые изменения UI проверяются при каждом этапе.

Сначала определить общий сценарий входа и возврата для T-010/T-011 и открыть локальный каталог. Проектирование регистрации и проверка условий Kinopoisk могут идти параллельно. После согласования переходов выполнить T-011 и T-007 с разделённой ответственностью за экраны аккаунта и личные действия. Гостевой внешний поиск проверять на fixtures после T-010, живой допуск оформлять отдельно. [Инвентаризация T-013](TASKS/T-013.md) независима.
