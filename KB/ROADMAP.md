# Этапы и критерии завершения

Стадии, ответственные, блокировки и выкладки — в [BACKLOG](BACKLOG.md).

| Этап | Зависимость | Критерий завершения |
|---|---|---|
| 0. Проектирование | — | Архитектура проверена и утверждена владельцем. |
| 1. Фундамент | 0 | Нативный запуск из PowerShell, миграции, smoke и PostgreSQL на CI с успешным quality-gate. |
| 1а. Визуальный прототип | 1, утверждённый эталон | Приёмка по [DESIGN](DESIGN.md#прототип-и-приёмка). |
| 2а. Серверная основа | 1а | Вход, синтетический поиск, приватное добавление, повтор и чтение после перезапуска. Права проверены в разных сессиях. |
| 2б. Kinopoisk | 2а | Поиск, кеш и импорт по [CATALOG](CATALOG.md). Живой режим требует отдельного допуска. |
| 3. Библиотека и оценивание | 2а | U01–U05, R45/R46. Формула, нули, теги, конкурентная запись и откат проверены. |
| 4. Рекомендации и обмен ссылкой | 3 | U06–U09 в отдельных сессиях. Гостевые поля и приватность по R45. |
| 5. Готовность к эксплуатации | 4 и допуск необходимых интеграций | Приняты основные пути и визуальные образцы, full, production check и HTTPS smoke пройдены. Восстановление, откат, reboot и мониторинг проверены по [OPERATIONS](OPERATIONS.md). CHANGELOG и тег соответствуют выпуску. Владелец разрешил запуск. |
| 6. Сопровождение | 5 | Обслуживание, наблюдение, копии, обновления и инциденты по OPERATIONS. |

Подготовка среды и согласованные тестовые показы могут идти параллельно продуктовым этапам. Значимые изменения UI проверяются при каждом этапе.
