# T-008 · Поиск и импорт из Kinopoisk API Unofficial

[Стадия и блокировка в BACKLOG](../BACKLOG.md).

## Цель и критерии

Реализовать [R47](../CATALOG.md#первый-выпуск--r47). Проверить явную отправку, локальную/внешнюю выдачу, импорт неполной карточки, повторяемость, расход запросов и деградацию без потери частной записи.

[Техническая спецификация и доказательства PR №9](https://github.com/FerMaxim/filmoteka/blob/8fcc4dd588ef3f4bb734f9bf485b2e70a84c99f4/KB/TASKS/T-008.md). ## Проверки

Отчёт PR фиксирует миграции, гонки независимых соединений, Playwright, повторный запуск и нулевые расходы живого API. Результаты относятся к SHA из отчёта.
