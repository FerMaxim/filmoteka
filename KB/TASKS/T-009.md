## Проверки

Метрика — сумма байт UTF-8 Git-блобов, без преобразования переводов строк. Активная КБ — Markdown в KB с исключением `AUDIT.md` и `HISTORY_*.md`. Общий вход — AGENTS.md, KB/README.md и KB/WORKFLOW.md плюс KB/CURRENT_STATE.md до P2 или KB/BACKLOG.md после P2. Строка задачи, выборочные разделы ENGINEERING и спецификации зависят от задачи и отдельно не измеряются. Байты файлов не измеряют расход токенов.

```powershell
$before = 'd0e0d0be5a208153f81007f706b78ebfd1d9489c'
$after = (git rev-parse HEAD)
foreach ($rev in @($before, $after)) {
    $active = git ls-tree -rl $rev -- KB |
        Where-Object { $_ -match '\.md$' -and $_ -notmatch 'KB/(AUDIT|HISTORY_[^/]+)\.md$' }
    $activeBytes = ($active | ForEach-Object { [int](($_ -split '\s+')[3]) } |
        Measure-Object -Sum).Sum
    $pointer = if ($rev -eq $before) { 'CURRENT_STATE.md' } else { 'BACKLOG.md' }
    $entry = @('AGENTS.md', 'KB/README.md', 'KB/WORKFLOW.md', "KB/$pointer")
    $entryBytes = ($entry | ForEach-Object { [int](git cat-file -s "${rev}:$_") } |
        Measure-Object -Sum).Sum
    "$rev activeKB=$activeBytes entry=$entryBytes"
}
```
