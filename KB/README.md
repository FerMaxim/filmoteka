# База знаний Filmoteka

Filmoteka — имя рабочего каталога. Название продукта открыто.

| Для какой задачи | Что читать |
|---|---|
| Начать сессию | [Регламент](../AGENTS.md) и [текущее состояние](CURRENT_STATE.md) |
| Определить поведение, проверить сценарий | [Продукт P01–P16 и сценарии U01–U09](PRODUCT.md) |
| Изменить интерфейс | [Дизайн D01–D14](DESIGN.md) |
| Проверить происхождение решения | [Журнал решений](DECISIONS.md) |
| Подготовить техническое решение | [Архитектура](ARCHITECTURE.md) и [аудит](AUDIT.md) |
| Разработка, PR, безопасность, БД, тесты и Docker | [Инженерный регламент](ENGINEERING.md) |
| Уточнить очерёдность этапов | [Дорожная карта](ROADMAP.md) |

P и D обозначают продуктовые и визуальные требования с их статусами, R — запись истории, S — эпизод исходного обсуждения. При споре последнее прямое уточнение владельца имеет приоритет. В журнале фиксируется основание изменения. Подробные исторические примеры остаются в [исходном пакете](../SOURCE_MATERIALS/).
