# База знаний Filmoteka

| Задача | Контракт | Проверка |
|---|---|---|
| Старт и передача | [BACKLOG](BACKLOG.md), [WORKFLOW](WORKFLOW.md) | `tools/task.py start`, проверка SHA при передаче |
| Изменение UI | [PRODUCT](PRODUCT.md), [DESIGN](DESIGN.md), [ENGINEERING](ENGINEERING.md) | Сценарий в браузере, снимки значимых изменений |
| Серверная логика | [PRODUCT](PRODUCT.md), [ARCHITECTURE](ARCHITECTURE.md), [ENGINEERING](ENGINEERING.md) | Формула, HTTP, права, PostgreSQL по риску |
| Интеграция каталога | [CATALOG](CATALOG.md), [ARCHITECTURE](ARCHITECTURE.md), [ENGINEERING](ENGINEERING.md) | Fixtures, квота, кеш, повтор и конкуренция |
| Запуск и выпуск | [Локальный запуск](LOCAL_DEVELOPMENT.md), [OPERATIONS](OPERATIONS.md) | Health, изоляция тестов, проверенный SHA, HTTPS и откат |
| Планирование и происхождение требований | [ROADMAP](ROADMAP.md), [DECISIONS](DECISIONS.md), [архив](ARCHIVE/README.md) | Сверить последнее прямое решение владельца |

P — требования, D — дизайн, U — сценарии, R — решения, S — эпизоды исходного обсуждения. Актуальность задач и выкладок ведётся в BACKLOG.
