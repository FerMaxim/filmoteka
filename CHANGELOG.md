# История изменений

## Unreleased

- КБ разделяет действующие контракты, карточки задач и исторические отчёты; определены передачи между разработчиком, ревьюером и агентом эксплуатации.
- Зафиксирован нативный запуск без Docker для разработки, CI и сервера; описаны обязанности эксплуатации, приёмка деплоя и откат.

- Добавлен каркас Django с проверками жизнеспособности процесса и доступности PostgreSQL.
- Тестовая PostgreSQL изолирована по запуску, а `full` включает всю коллекцию pytest и проверки на чистой базе.
- Локальный запуск из PowerShell и CI используют нативные процессы Django и PostgreSQL 17. Постоянная dev-база отделена от одноразовых кластеров проверок.
- GitHub Actions кэширует Python-пакеты и сохраняет краткий отчёт проверок.
