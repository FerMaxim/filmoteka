# История изменений

## Unreleased

- Harness 2.0 P3: сокращены действующие контракты, архивированы доказательства завершённых задач и сохранены проверки реестра и CI.

- T-009: единый реестр задач, проверка старта по Git и сводка для передачи из отчёта проверок.

- Исправлена защита прямого запуска браузерного стенда от записи в dev-БД; проверки главной учитывают реальные защищённые переходы и возврат после входа.

- T-005: добавлены серверный вход/выход, общий синтетический каталог и приватная библиотека PostgreSQL с защитой CSRF и повторяемым добавлением. Проверка обновления прежней auth-схемы и перезапуска приложения включена в full. Оценивание остаётся следующим этапом.

- T-008: добавлены поиск Кинопоиска по отправке, общий кеш и импорт в приватную библиотеку. Локальный отказ резерва не продлевает паузу API. При отзыве разрешения метаданные скрываются с сохранением личных записей. Живой режим выключен по умолчанию.

- Утверждён визуальный эталон Свет 04+ / Плотный; обновлены дизайн-контракт, персональный фон и пять вкладок. Прежний T-003 возвращён на перенос эталона; новая реализация ещё не выполнена.

- КБ разделяет действующие контракты, карточки задач и исторические отчёты; определены передачи между разработчиком, ревьюером и агентом эксплуатации.
- Зафиксирован нативный запуск без Docker для разработки, CI и сервера; описаны обязанности эксплуатации, приёмка деплоя и откат.

- Добавлен каркас Django с проверками жизнеспособности процесса и доступности PostgreSQL.
- Тестовая PostgreSQL изолирована по запуску, а `full` включает всю коллекцию pytest и проверки на чистой базе.
- Локальный запуск из PowerShell и CI используют нативные процессы Django и PostgreSQL 17. Постоянная dev-база отделена от одноразовых кластеров проверок.
- GitHub Actions кэширует Python-пакеты и сохраняет краткий отчёт проверок.
