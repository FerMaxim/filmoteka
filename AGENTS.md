# Правила Filmoteka

- **KB-First.** Открой [указатель](KB/README.md) и строку задачи в [BACKLOG](KB/BACKLOG.md). Начни и передай задачу по [WORKFLOW](KB/WORKFLOW.md). Ищи нужные разделы через `rg`, пропускай зависимости, сборки и полные успешные логи.
- Владелец утверждает продукт, дизайн, расходы и существенные архитектурные изменения. До утверждения архитектуры работай над проектированием. Полномочия трёх ролей, Git, безопасность и проверки определяет [ENGINEERING](KB/ENGINEERING.md).
- При проектировании, изменении и ревью UI используй [проектный Anthropic frontend-design](.agents/skills/frontend-design/SKILL.md) и [утверждённый дизайн](KB/DESIGN.md). Значимые экраны проверь в браузере и приложи скриншоты.
- Django и PostgreSQL работают нативно, без Docker и Compose. Выкладка требует определённой среды и полномочий владельца по [OPERATIONS](KB/OPERATIONS.md).
- Сохраняй чужие изменения и SOURCE_MATERIALS. Обновляй контракты и фиксируй фактические проверки по WORKFLOW.
