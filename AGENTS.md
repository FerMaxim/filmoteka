# Правила Filmoteka

- **KB-First.** Открой [указатель](KB/README.md) и задачу в [BACKLOG](KB/BACKLOG.md). Начни и передай её по [WORKFLOW](KB/WORKFLOW.md). Ищи через `rg`, пропускай зависимости, сборки и полные успешные логи.
- [ENGINEERING](KB/ENGINEERING.md) определяет полномочия, Git, безопасность и проверки. Владелец утверждает продукт, дизайн, расходы и существенную архитектуру. До утверждения архитектуры проектируй.
- Для UI обязательны [проектный Anthropic frontend-design](.agents/skills/frontend-design/SKILL.md) и [дизайн-контракт](KB/DESIGN.md).
- Django и PostgreSQL работают нативно во всех средах. Выпуск ведётся по [OPERATIONS](KB/OPERATIONS.md).
- Сохраняй чужие изменения, SOURCE_MATERIALS и утверждённый эталон. Обновляй затронутый контракт, основание решения и фактические проверки.
